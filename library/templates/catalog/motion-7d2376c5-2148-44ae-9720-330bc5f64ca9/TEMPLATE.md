# Template browsing and remixing

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-7d2376c5-2148-44ae-9720-330bc5f64ca9`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/05bf5f86d44c0c8538a423417841bc97860579d5a1e121b08f7f2a01f7227a2d) · [Published package](https://r.open-design.ai/files/a17f839aa96ce995fc46d5865c2e800fae5c9a905be7b9280d9d5a0b36f1dc21). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
