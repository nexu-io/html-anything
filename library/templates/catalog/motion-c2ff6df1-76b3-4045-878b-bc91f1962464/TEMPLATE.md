# Figma — Generate, edit, animate

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-c2ff6df1-76b3-4045-878b-bc91f1962464`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/fe838a8088c83ac8ff03457f73135e49eb1ac4d5d5b9ecf5d7a4f75d4e0513a1) · [Published package](https://r.open-design.ai/files/43c75a6406cb43cad9a8367874929c25771b570cd9a9bd3ebbe68108f0d97830). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
