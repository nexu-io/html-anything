# Multi-model API network

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-0c91857e-f630-4d75-85ab-1feec5566c46`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/cffa4025c7cc71da6597b66e85668cc82f0c651e2c45025f293435d592804442) · [Published package](https://r.open-design.ai/files/eed7600471a1a2e15d89aa6126ec91d0b93dc844943db614fd356ac60b317d88). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
