# One conversation produces several formats

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-315c1cab-71b0-4bec-a20c-b57f2418e88c`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/aa94541a23228cf433707162ecd0410eb2941123cf12157cc421b16461c3f1ef) · [Published package](https://r.open-design.ai/files/3c4fb811f3cd60d7ed0c7406dccc950c55408f5231a9c7655789c66ae5253d02). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
