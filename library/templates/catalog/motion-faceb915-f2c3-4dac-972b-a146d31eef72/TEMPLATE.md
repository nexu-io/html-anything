# Perplexity — Run tasks locally

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-faceb915-f2c3-4dac-972b-a146d31eef72`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/e97d25cc8592bac37cb2410a977d9632a13b4cba445be9d565f429e0f8da8640) · [Published package](https://r.open-design.ai/files/f5ee93ffba499f5cbe1231c369957acc195e010d79df6150ab36299e43301acd). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
