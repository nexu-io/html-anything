## 先展开场景，再开始说话

影像进入后虚化并叠暖色光晕，字幕随后出现；背景降低细节以支持阅读。

字幕是词组增量显示，退场后留口号，最后回到初始按钮。

| 时间 | 段落 |
|---|---|
| 0.00–0.50s | 语音圆钮 |
| 0.50–1.20s | 圆形遮罩展开 |
| 1.20–2.20s | 生活画面填满 |
| 2.20–6.00s | 字幕逐词出现 |
| 6.00–6.60s | 遮罩收回 |
| 6.60–9.50s | 口号留读 |
| 9.50–11.46s | 恢复圆钮 |

## 一句对话的容量

替换生活场景和一句对话；保留按钮→情境→话语→按钮的闭环。

字幕建议两行内，按词而非随机字符揭示；音频同步需要另行对齐。

## 元素与制作规则

语音圆钮 / 同心圆遮罩 / 背景影像 / 逐词字幕 / 口号

- 同一中心圆从按钮扩张为影像窗口，再收回按钮；保持空间身份连续。
- 影像进入后虚化并叠暖色光晕，字幕随后出现；背景降低细节以支持阅读。
- 字幕是词组增量显示，退场后留口号，最后回到初始按钮。

## 内容替换

- 替换生活场景和一句对话；保留按钮→情境→话语→按钮的闭环。
- 字幕建议两行内，按词而非随机字符揭示；音频同步需要另行对齐。
