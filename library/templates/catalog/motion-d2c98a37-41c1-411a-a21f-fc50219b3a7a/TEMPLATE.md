# A new identity assembled from particles

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-d2c98a37-41c1-411a-a21f-fc50219b3a7a`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/1109536a6668680697475afb24da30d6ffc587fb1d03a0aa119dd99405e1da3e) · [Published package](https://r.open-design.ai/files/d654f62cda43ae6c4b5dffd6058df917e203377a3df6320e58cc0cfe392a1c31). Videos and duplicate archives remain in the CMS.
