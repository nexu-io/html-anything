# Figma — Figma Motion

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-e6ac921a-f56f-4170-a2be-938cec5d028b`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/d4b2bd6881774c3ac7b836cc4ec7ba178eecd63c9f1d9a184521b473992e8616) · [Published package](https://r.open-design.ai/files/542ea81fb79391c525dfa9efbf77e71b61281aac35264e1145ba53f71181f4ef). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
