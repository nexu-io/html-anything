# Conversation branching

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-c70c9db2-6726-4aa0-81a2-bcef85c19402`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/ebbd8b05627cddc973b385640df5b406dfae865f534c626edf2e4bcefc11740a) · [Published package](https://r.open-design.ai/files/0fa81b90fa950e26d7a57117e69f26f2ee6615cfe95ae1d27d2ef2e83488dc49). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
