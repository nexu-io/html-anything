# The web as living memory

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-f8941c74-b760-411c-b92f-6d838250ecc9`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/a13fda11ffdf77f30646169b0f0cbd8d5aeaf4fc8c740b58cf5edfb9693d7d26) · [Published package](https://r.open-design.ai/files/5ea68b2342ff623a31a170addaca8f8181999a555d48d124d89d587f1374d48d). Videos and duplicate archives remain in the CMS.
