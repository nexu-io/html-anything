# Full-frame pattern cycles

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-e3fe6179-acf0-4e3f-a8fe-27efd50a6d1d`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/2475f39d3ce8870ba80d8926f559eb8b3049fb5ff8de8573077bcc4a865e3eee) · [Published package](https://r.open-design.ai/files/23840ed92cd65b78ab32931b73f20b64c1626971dfacfb5c4db350f96db94757). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
