# Cloud computer workflow

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-eb5e7505-5597-469a-81d0-af00335f029f`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/c54e460713daeea894a25475103d1227fb10c2a820a0be83817195f8bec56603) · [Published package](https://r.open-design.ai/files/ba00e07a5e3fc31ff1403c3850798d878225474a2754fb0e543c88f33679c11b). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
