# Conversational Design Workflow

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-9f3b5395-c61e-45aa-97db-f164e762e61a`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/79ccb26330339704efdc79c64460dabe7a2bbdee26e468f944bdddd418db1864) · [Published package](https://r.open-design.ai/files/9b668079310df5fb5b8552c4fbe477927b65b1a7a62f9c4f036ea5603bca7205). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
