# Organic Cloud

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-d1af6c0e-6066-4444-9b25-8773ad6cf2f8`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/9ff4e0be35425397f384d9ab31e733e18e2a4201c54292b21884277ff3d464ba) · [Published package](https://r.open-design.ai/files/b0e2f00889802fb3ac037ab44289f66d06807ff90c86b2f8f04780a261e32eda). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
