# Live app publishing

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-a55bd50a-ab7b-4f47-9cff-8b6faddfadf7`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/4b599c8c8536ba42cb83477cddc2213bc62f0df0da4a2e4ac7fd581e9d2f1ede) · [Published package](https://r.open-design.ai/files/8c4834bc9d7933dc907664baa33158c0d787bdbaa4a1c89bd8836c699f617dc5). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
