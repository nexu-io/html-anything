# Motion design workspace

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-90713ad1-ac50-4d2d-ba9e-ddf718959fe2`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/418b35bbe01798d8ce9b5c4538fcf3cb794174b955ab83f6d6a08b6814f9d230) · [Published package](https://r.open-design.ai/files/732eb14735c6998e3bfaa9c3415c6d05bff1ad14d4767918484dd354219b1e3e). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
