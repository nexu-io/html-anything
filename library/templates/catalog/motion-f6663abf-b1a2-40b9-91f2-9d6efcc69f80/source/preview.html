## 保留角色一致，改变输出形态

草图、彩色人物表与动画预览应能认出同一组角色。蓝色气泡只表示用户输入，结果放浅色卡片，不混淆两种角色。

## 最后从内容回到服务标识

动画短暂播放后切到标志，再留网址。替换题材时先准备同一对象的草图、设定图和动作三个版本。

|---|---|

| 4.50–7.50s | 等待与人物设定图 |
| 7.50–10.70s | 要求转成视频 |
| 10.70–12.00s | 动画结果 |
| 12.00–15.50s | 双标志 |
| 15.50–17.63s | 网址 |

## 元素与制作规则

草图附件 / 用户消息 / 加载占位 / 人物设定图 / 视频结果

- 第一条请求把草图变成人物设定图，第二条再把该结果变为动画。聊天视图向上滚动，新结果从底部进入，保留上一条消息的联系。
- 草图、彩色人物表与动画预览应能认出同一组角色。蓝色气泡只表示用户输入，结果放浅色卡片，不混淆两种角色。
- 动画短暂播放后切到标志，再留网址。替换题材时先准备同一对象的草图、设定图和动作三个版本。

## 内容替换

- 换成目标角色与动画，维持连续两轮转换和聊天层级。
