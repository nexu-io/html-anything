# Airtable — Custom interfaces

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-3b1813cf-f2fe-4d8a-add4-8f3a49d06982`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/127e3c247ceb8c8cffc85cd96ca86d5bcaa49ee04e025445d7d15e7ea9a97c42) · [Published package](https://r.open-design.ai/files/732511452628c612b7aeaa6d66e902552d3fad0450a83136a88134f23fbc1a3f). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
