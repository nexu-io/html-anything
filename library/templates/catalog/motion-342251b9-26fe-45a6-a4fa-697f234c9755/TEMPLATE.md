# A desktop tool shown through focused actions

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-342251b9-26fe-45a6-a4fa-697f234c9755`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/623126fb8d13b6aa39b09812add9de0a790deea3f8ab937b6cc5e26aa40dd578) · [Published package](https://r.open-design.ai/files/e3e4f95d4dc5590617bc4ea1ac91b0dfffe135ab7547ba385be8dabfccce6f35). Videos and duplicate archives remain in the CMS.
