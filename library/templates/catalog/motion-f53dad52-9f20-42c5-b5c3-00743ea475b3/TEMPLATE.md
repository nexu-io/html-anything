# Agent-assisted motion editing

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-f53dad52-9f20-42c5-b5c3-00743ea475b3`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/a2d2f2556b68cb578fa536f26b9c42a1506ef920135fbb0ec097d91b62e0eaff) · [Published package](https://r.open-design.ai/files/b38faa837de2efade9a2b4df678d37fe9862e164f7c1862ff3ae404be2bdf853). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
