# Figma — Make-a-thon

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-f878182e-c863-45eb-ac54-2e472890987b`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/5c53d311ae15f8c37ba2ad02f8630470755f6ffc7d40e2731d5a37da7ca16bf6) · [Published package](https://r.open-design.ai/files/4777cfaaec3afd683767016f09d0d4f5cd43ca22b4f825e151b7c72ed5f2a4c5). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
