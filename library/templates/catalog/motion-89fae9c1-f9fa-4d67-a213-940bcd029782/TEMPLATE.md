# A configured assistant becomes a template

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-89fae9c1-f9fa-4d67-a213-940bcd029782`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/23f37aa5aa76bd0496dbe7e3c7f2ee4be8df052a77f0009647b614ac1bd8f5fd) · [Published package](https://r.open-design.ai/files/0f0d79fd9d1c9e85b21a690f236a0959a18ae7a6d7dbfc7459362df22909693c). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
