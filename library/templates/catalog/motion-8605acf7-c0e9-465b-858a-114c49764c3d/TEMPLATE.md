# Prompt-to-website launch

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-8605acf7-c0e9-465b-858a-114c49764c3d`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/4564758acd84fd2f95e35213799473c4811bead609a4ba11f846cd580c561beb) · [Published package](https://r.open-design.ai/files/b83825029af41fc9b3fcd59e2957270f9cc36839c8f4266fd42f8d36cdfd463a). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
