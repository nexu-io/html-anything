# Figma — Design to implementation

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-ccb4e364-1666-4672-80d4-cb68fb591bad`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/4c449f3e5b80708a9a957b0cd901fc00cc19ccb9aadc7368c75921453d79090f) · [Published package](https://r.open-design.ai/files/7d6ecdd288ebfdeab647af8c89d2ff158d3dee4ee3cff41e48d4742e627a908b). Videos and duplicate archives remain in the CMS.
