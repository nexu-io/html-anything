# Search across people, places and things

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-1da97ff4-695c-404a-8c47-c0a0ab2921aa`, stage the change and run `npm run templates:check`.
