# Model inspection workflow

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-c3a91b2d-1618-4d3c-9446-4f316797dcd9`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/d497595e34a6f9010d293814e2898db3edb0fc3bac8645140a068f49a3ba7010) · [Published package](https://r.open-design.ai/files/0d415b0f42eab8a5eeddffd4cb4de03d7b81c753de860ebd2b0df1147ee58a8b). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
