# Creative plugin workflow

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-b18272fd-07c8-4ab9-b7dc-26311fa5a29a`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/45cbde909d446da412823b2f769bef12ce7515ef969803f250c13cbbb91fc850) · [Published package](https://r.open-design.ai/files/dfb8e2edfc6b4d7de839678b5753bc75fa1812ba9baebe944fcb77844fbc8d4d). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
