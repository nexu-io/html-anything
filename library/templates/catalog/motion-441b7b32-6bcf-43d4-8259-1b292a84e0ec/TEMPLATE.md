# Graphic Cloud

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-441b7b32-6bcf-43d4-8259-1b292a84e0ec`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/a726a68f8942d84c0ede1328b9d6e05c65659b0287e5ceb860475ec43da089dc) · [Published package](https://r.open-design.ai/files/10cf70d4e5f279e771b970c67a7ac5ccb8959771e4172e404c43bb1be41251f4). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
