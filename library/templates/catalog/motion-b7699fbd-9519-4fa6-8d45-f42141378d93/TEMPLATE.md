# Supabase — Supabase Pipelines

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-b7699fbd-9519-4fa6-8d45-f42141378d93`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/02a57607b3ccdb939d84031e7079a983f12e9805b0cc133f2493f093b7de9d6b) · [Published package](https://r.open-design.ai/files/eb61538717a20adbe47177c05387d7fa520cbcd0327e781bff3a8a02c2ebb221). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
