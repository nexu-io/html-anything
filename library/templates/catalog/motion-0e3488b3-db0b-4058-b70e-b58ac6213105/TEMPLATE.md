# Installing the product name

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-0e3488b3-db0b-4058-b70e-b58ac6213105`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/a15f99e29f823ce04c94d2d2eed3e4854a9b6d13b41ea577093e4975d26fab74) · [Published package](https://r.open-design.ai/files/6e39d40d6fd03288aad6a9ef16647ff65b4e9c998e3876d183598d69f2d22606). Videos and duplicate archives remain in the CMS.
