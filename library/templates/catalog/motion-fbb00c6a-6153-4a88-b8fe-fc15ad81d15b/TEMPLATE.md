# Focusable planet carousel

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-fbb00c6a-6153-4a88-b8fe-fc15ad81d15b`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/b81592d5e94d6516bee0dfcc6f2c68657ed4c36e5031a8372c774aa2e193a13d) · [Published package](https://r.open-design.ai/files/31af532ac5988e6cfae863af2ae5e36992072d913e2ecea4ef93f876ac671042). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
