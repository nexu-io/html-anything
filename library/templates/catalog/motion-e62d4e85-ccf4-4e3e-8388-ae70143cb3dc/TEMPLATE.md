# Creative Cloud

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-e62d4e85-ccf4-4e3e-8388-ae70143cb3dc`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/e8d62e79d54c2c12b002b0556fa67380064055e76faa16b6966eb9877a3b1c4b) · [Published package](https://r.open-design.ai/files/ba3301e3753327ee9044a2075c7bea2af84d0f5c772cd7d4c079c38f60c2b5df). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
