# Several creative formats in one editor

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-b4a2bd67-b577-4e6a-8475-966edd41d474`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/48f73c9e320b619d37015f9f068eeefac9b8d1ec8643267e3da9a45515ff3e08) · [Published package](https://r.open-design.ai/files/f353b4681768ffb910a23cd51152552a95ae80f5e647e0c97172e6964e8c8e5f). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
