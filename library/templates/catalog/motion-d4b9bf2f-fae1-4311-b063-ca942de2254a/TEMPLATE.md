# Teach the agent a reusable style

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-d4b9bf2f-fae1-4311-b063-ca942de2254a`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/67c9fa093076dcfa7073dbf29318a58b675321563c23feec0a12cca18894278a) · [Published package](https://r.open-design.ai/files/7ac1f3bd1c8d9ce0dac9b8a8d8bb9b09a326e73f829ea97a679edfdedf52365a). Videos and duplicate archives remain in the CMS.
