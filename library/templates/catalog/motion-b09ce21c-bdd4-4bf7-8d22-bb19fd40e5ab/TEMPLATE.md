# Perpetual order workflow

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-b09ce21c-bdd4-4bf7-8d22-bb19fd40e5ab`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/6d16a00119d8ffd9d98c6e94b90769ea44f0b00b30495bfecccc9f9a171981f4) · [Published package](https://r.open-design.ai/files/274a6b604d0a20246698c30b52248ea4d4ed18fdf1d4e1b6acb04760800b2a54). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
