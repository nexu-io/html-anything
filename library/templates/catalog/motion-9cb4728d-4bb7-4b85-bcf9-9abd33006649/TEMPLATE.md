# Beautiful.ai — Build your presentation

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-9cb4728d-4bb7-4b85-bcf9-9abd33006649`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/e3a83748e2762a83d18221ad07dc843ee8d7afddc6a76bad9e72a99cf6af81ca) · [Published package](https://r.open-design.ai/files/12ba8bf69a3f4b5efaec2ee5f49c2689eebc0271c8205ff03735c5d3267870d2). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
