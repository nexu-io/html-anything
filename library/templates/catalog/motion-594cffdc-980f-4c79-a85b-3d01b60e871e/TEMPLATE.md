# Rive — Interactive motion

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-594cffdc-980f-4c79-a85b-3d01b60e871e`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/8c5d47dd80e1a3769a97b35db1100c8b11de1f6b0164508523c945dea843460e) · [Published package](https://r.open-design.ai/files/49fb8f0f0cc90a77c44570b5af58e20ec8d8a9d0de1e5377c6f56c148af51274). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
