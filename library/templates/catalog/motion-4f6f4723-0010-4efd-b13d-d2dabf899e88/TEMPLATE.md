# Slide creation and variety

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-4f6f4723-0010-4efd-b13d-d2dabf899e88`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/bc139221f4dca9836886593d3c4a99f3e35e803a5c4ddf68db69e2b3b5445910) · [Published package](https://r.open-design.ai/files/c2e5c0ca42a24fe65af484b4814cdccb4b940f4664c3331616481836442feb91). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
