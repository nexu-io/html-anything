# A people search becomes a directory

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-133fd03a-4447-4e39-9b68-a74439ab34c0`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/302ab0a44e2d31f99f341133d7a1a6129387c04f363be823b69c968a0a81097e) · [Published package](https://r.open-design.ai/files/d1f00e78e8196b2ad2a61f49b9daddad014358e62d4cc311bfb73674ac0ab346). Videos and duplicate archives remain in the CMS.
