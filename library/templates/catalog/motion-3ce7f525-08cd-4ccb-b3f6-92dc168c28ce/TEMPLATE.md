# Goodnotes — Goodnotes

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-3ce7f525-08cd-4ccb-b3f6-92dc168c28ce`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/865bd18802333be9bc1f8eae6b0dfbe509eae05252fef4077192a96c604126ae) · [Published package](https://r.open-design.ai/files/900fca293b2ebdd0e83e1503e527d00923b26479d0948d2a335f4f1d886b3bb4). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
