# Prompt, preview and publish

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-c77ccf22-57cc-4afb-b398-aab0bb7617d3`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/5213099fa43669f9e02fbaf331d35b5d5b2aaebd0b94ca1c668cbf58f1d93c7f) · [Published package](https://r.open-design.ai/files/54dae7fe8cc05eed839e205effa15c4a5f5f358c10f4188393c537723049edae). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
