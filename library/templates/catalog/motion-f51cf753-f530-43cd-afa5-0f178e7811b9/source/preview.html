## 从密集叠入到稳定留读

前 3 秒连续叠入窗口，3–8 秒保持主标题留读；末段按相反次序撤窗，回到档案底板。

| 时间 | 段落 |
|---|---|
| 0.00–0.30s | 文档底板 |
| 0.30–1.20s | 历史素材窗口叠入 |
| 1.20–1.90s | 像素角色窗口 |
| 1.90–3.00s | 中央标题窗口 |
| 3.00–8.10s | 多窗口保持与局部内容变化 |
| 8.10–8.80s | 窗口反向退场 |
| 8.80–9.22s | 回到档案底板 |

- 主标题停留期间，角色与访谈等内部内容继续变化；窗口外框与内容动画分开描述。
- 退出时撤去上层窗口，露出起始文档，让片段闭环。
