# Product acceleration workflow

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-4aaa2afc-a75f-4ce4-a3c5-eb620ed706e5`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/5d841ba56feb5659d5a08ac346f1eab8b71974fb2a7d0e27886b71045c7cec1d) · [Published package](https://r.open-design.ai/files/e7e7d615550368bddbefb9cc36544a164bde7bc9493bcfa685d5cc2a965d89da). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
