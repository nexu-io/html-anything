# Recording opens into a multitrack arrangement

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-734ef479-a7b7-458a-b488-ad0f6a0498b4`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/bd1be97926b5d0a5b5feb751524949c924bef0afe4af20dc493395100ae40323) · [Published package](https://r.open-design.ai/files/076fb247e6b4f38f572cf1b8d5801914b4e452a0e76c55a519fe305037e82f6f). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
