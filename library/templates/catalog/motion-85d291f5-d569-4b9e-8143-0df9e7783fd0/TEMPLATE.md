# Import source carousel

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-85d291f5-d569-4b9e-8143-0df9e7783fd0`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/62d52315a8db5af06b2e91ed9b101eb30b300e1419ef3d01f997607528beb3a2) · [Published package](https://r.open-design.ai/files/3ca1c724566ef041213a716f49280e72de960a8131353933be62e0e9fdf2c233). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
