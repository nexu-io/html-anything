# Music library and creation

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-fb72e5e5-872c-4981-b137-4533a72567fe`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/059ef249a862ecb3093a3913f80300ac867e0e7506c7f26c8d45610e1176c525) · [Published package](https://r.open-design.ai/files/76d0e7746c25b69ca8b9e5e0d1c7cbdb6dfb2601557bbd7061b56e62f8c098f5). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
