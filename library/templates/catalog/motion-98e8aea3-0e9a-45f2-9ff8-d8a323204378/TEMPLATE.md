# Demand becomes a desktop release

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-98e8aea3-0e9a-45f2-9ff8-d8a323204378`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/4994945e52e3d9cf100caad1974d4e6c4483fce5de8972968066adcff56a8699) · [Published package](https://r.open-design.ai/files/10f7819af3e505b617519bed138a51d264a35c6abaeb6fa638d29b0a5e7d8f45). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
