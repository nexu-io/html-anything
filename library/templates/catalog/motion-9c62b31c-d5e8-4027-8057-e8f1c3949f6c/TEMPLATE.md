- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-9c62b31c-d5e8-4027-8057-e8f1c3949f6c`, stage the change and run `npm run templates:check`.
