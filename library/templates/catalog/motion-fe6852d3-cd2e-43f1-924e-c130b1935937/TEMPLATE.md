# One grid, changing worlds

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-fe6852d3-cd2e-43f1-924e-c130b1935937`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/2546cb66338ac4ac7b4460124d1b7039b9f5f040eb47469f789c59cff359a480) · [Published package](https://r.open-design.ai/files/da90acd2b259a81ec3fef8cc9a66c26c1554eea68892d027384c43ef84f47427). Videos and duplicate archives remain in the CMS.
