# A quiet website with playful cursor trails

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-018becab-0461-43d9-8e84-79833fd1f831`, stage the change and run `npm run templates:check`.
