# Mobile building launch

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-ffaef2b8-7833-4612-ba45-0efd992cc43a`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/c8e9a3cc995b90fea5c118d4d90a54958907d2cce0ae61ba03e164921927da7a) · [Published package](https://r.open-design.ai/files/d01dea396d657ed3ff9304868d89c7938ad2ef5b81d6d563e09550e864296f15). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
