# Animated media and iterative editing

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-7427c442-35ee-408f-9c33-4280ad2d3465`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/853850d96cc15aa5f3a436de8e70cdada2a6fb8e4615655e811229170e9a46d4) · [Published package](https://r.open-design.ai/files/6bbb84231ab49675e95b3cdbcd08ae9c46b42f978f77a3fd1fefb2a5f888021f). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
