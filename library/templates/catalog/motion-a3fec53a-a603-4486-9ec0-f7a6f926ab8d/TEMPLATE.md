# A world connected by computational fragments

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-a3fec53a-a603-4486-9ec0-f7a6f926ab8d`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/916196c337a97d1be0f1db89cdc85835a526d9b6edf36e44c08f7c2a3afc2cbe) · [Published package](https://r.open-design.ai/files/2305e8181decc8664a42a09657cfabdfcb711bf01dfe8f0104633895d52d5af2). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
