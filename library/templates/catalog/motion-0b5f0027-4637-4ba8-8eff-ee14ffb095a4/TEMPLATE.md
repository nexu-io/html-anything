# Tablet creation and review

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-0b5f0027-4637-4ba8-8eff-ee14ffb095a4`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/c2b7ff4ed393ff8f75a2127a5c52bee3f70cc31fa531bd4f432d5aeef2d5933c) · [Published package](https://r.open-design.ai/files/8022f727ab52449c54f39235b7b30be2a80e3ebb20974459cac6e15c8f1bbcb7). Videos and duplicate archives remain in the CMS.
