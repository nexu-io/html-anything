# An editable photo-mosaic numeral

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-030d40f1-a081-451c-b557-a0bea9703616`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/b0349782699a8ab77adf28e6feb61cf2c75d4f61f0d0bc47dd39c7255965a995) · [Published package](https://r.open-design.ai/files/b6f53b6d3080114b0d36edb61124f7a9241c8ec5afcdd7c73558b88da96298bd). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
