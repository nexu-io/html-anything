# Descript — Create social clips

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-74408712-50e0-43ac-a167-1a11297cdae0`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/6fb1680c2ed25d82d192a4fffe2d73d394a4ac094c62e6e3501523eae5e4b26e) · [Published package](https://r.open-design.ai/files/1e33e4418fb0276dd8904920f637a0da2cf9a239c09cb6f72965215bef75613d). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
