# SDK code and terminal

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-63434ede-a918-4ec1-a99e-ba12e87d4063`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/3dd058860ea097a33616aec188126ee17daef8509e1592fd8b03afef8569dcaf) · [Published package](https://r.open-design.ai/files/057cf781ad32174f7038ced7b558aac0155809b75af76d3bdd7b6dda197a5717). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
