# A focused template carousel

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-ab741f6c-6d55-4fac-9862-0a0914806c2b`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/a7b08ce04cdd3e246a7eec8f23d394ab68e1b6deabe93b9a2d81b65650b16e63) · [Published package](https://r.open-design.ai/files/68a0662d2071c41bd8677ba2dd4e0432d9a44d660f3d75de5f4df4fecbd93df6). Videos and duplicate archives remain in the CMS.
