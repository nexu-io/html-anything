# From a brand URL to an ad family

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-9fc27ae8-90f1-4745-af4f-00f390c206a2`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/abc83f47046889dcb995a5816bf6e240a46e19a759f45508f9616410c5f205c6) · [Published package](https://r.open-design.ai/files/b0603b35c6693faef747fffd796bde909481f00adbce33c563ba1063340e618f). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
