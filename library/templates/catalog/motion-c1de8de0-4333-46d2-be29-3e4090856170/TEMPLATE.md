# Prompt-to-media workflow

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-c1de8de0-4333-46d2-be29-3e4090856170`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/d9b0a47abf7cba1d7e65d795be947668db623bab696fc67e2f525696b0cbeb34) · [Published package](https://r.open-design.ai/files/b71ba8da664dc3138c43fc0345015edc9ea3483e44e6fa67974d5fd9da077e43). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
