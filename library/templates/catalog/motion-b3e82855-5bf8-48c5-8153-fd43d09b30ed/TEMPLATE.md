# Linear — At your command

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-b3e82855-5bf8-48c5-8153-fd43d09b30ed`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/e0059069b6c50d689bdf825434f1bd5b2485d4f653c0b65b8d13c059b7066ac1) · [Published package](https://r.open-design.ai/files/2f51b901ab49b772ae63103ad3d2dc3e2a38d36a4e350e68941ef0982b04b90d). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
