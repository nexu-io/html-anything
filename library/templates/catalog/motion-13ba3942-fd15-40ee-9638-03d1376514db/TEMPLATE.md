# From individuals to interactions

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-13ba3942-fd15-40ee-9638-03d1376514db`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/1e39b0848e994ad1a9609d0462abbb0e8bc36117e497d93af6620100f1f36c17) · [Published package](https://r.open-design.ai/files/b97363c16cbdf320d94b0355026a51586d32a76fb418b36844a189313937f148). Videos and duplicate archives remain in the CMS.
