# Reusable skill library

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-6169c2d0-a372-445e-96a3-e5eb43b00656`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/8c7bb01bbed13b6299c472906fdb5350289ff1dcd424515827888f14c2c26d90) · [Published package](https://r.open-design.ai/files/2332603b6965d112cc968f02e4cf2a18a80c17d7550924ac7613427bb3402c87). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
