# Software factory overview

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-478a2c75-2a13-435a-9b44-d730aca6c67c`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/7f8d4ae948ffe80eb7bf9599610b2b1b10072e96c71f56f1eeb15ee95b7f1309) · [Published package](https://r.open-design.ai/files/d96908dab48bf7197896e15c11730e0129a6bc2f423a5db6f97f9f59fe6f7659). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
