# A workspace for multiple coding sessions

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-cbb18ecc-34d6-43f2-bcd9-5d287ff82b83`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/57c458e9b9f0d65976faed734c5fd87c3c372a4873af77a08bb6b6b2d8a29828) · [Published package](https://r.open-design.ai/files/af90c65a5e51307d8534267011b2e70d5bf59faf0c905c246b0e7b2b64514372). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
