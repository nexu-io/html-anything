# Linear — Custom environments

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-81c409d2-46e9-4c90-bcde-a0de2106f81e`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/40f627e830cea0d10a2a380917b8f7d89ac473379c29ea19b177c8a74aebe2ad) · [Published package](https://r.open-design.ai/files/e1601f48a4ec4c35330971ee4d6c15305878ba85a79ab64200bd10a8590b6153). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
