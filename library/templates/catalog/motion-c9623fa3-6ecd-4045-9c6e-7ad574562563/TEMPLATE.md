# Figma — Bring code to the canvas

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-c9623fa3-6ecd-4045-9c6e-7ad574562563`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/c125b41e1370bb3c17925a89a1c50c579a0e917838f30c293e84eb51e035115f) · [Published package](https://r.open-design.ai/files/7f97fd69d5d36f086c50e51eb41f54e20cffc61fcbbed6edc4e89c6126b8b6e3). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
