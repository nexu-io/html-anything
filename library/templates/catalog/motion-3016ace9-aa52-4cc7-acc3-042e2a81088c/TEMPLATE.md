# From prompt to a published app

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-3016ace9-aa52-4cc7-acc3-042e2a81088c`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/f17042b1a56b9de1a8ad8b1f5c009accbc0b9f3f47d097fcdde1d343a3730b41) · [Published package](https://r.open-design.ai/files/6ac18d3950c9e4d61c0a0225a3289b2299b9f49eb7933c1ed430df64c60d167c). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
