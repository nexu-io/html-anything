# Figma — Image editing

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-d214ebc1-b1cd-4615-8d40-d580632e8f29`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/d6a9614d7541cb6f1ea927bfd596af0daaf1fd339ae14e7696402e58a52c227b) · [Published package](https://r.open-design.ai/files/a5592db43f954534ad8d1a0764720127ef7144fe5c195e898198439892a8dd7d). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
