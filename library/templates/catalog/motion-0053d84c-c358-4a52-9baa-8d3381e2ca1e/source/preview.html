## 所有元素共享显像管质感

线条使用低饱和绿白，黑底不加其他彩色装饰。扫描纹、少量抖动与轻微色散统一覆盖网格和标志。

## 由平面标志折回空间

双标志停留后各自折成网片，再拉长成新的通道，最终淡黑。替换合作方时保持左右重量一致，折叠动作在留读后发生。

| 时间 | 段落 |
|---|---|
| 0.00–1.00s | 暗场 |
| 1.00–7.00s | 隧道展开 |
| 7.00–10.00s | 隧道收窄 |
| 10.00–15.00s | 双品牌 |
| 15.00–18.00s | 标志折叠 |
| 18.00–22.00s | 网格折片 |
| 22.00–24.00s | 恢复通道 |
| 24.00–25.12s | 淡出 |

## 配色与字形

#000000 · #e0ead7 · #93b47b · #355c3f · #17241c

## 元素与制作规则

透视隧道 / 双品牌标志 / 折叠网片 / 扫描纹

- 透视线从中央小孔扩展成四面网格，前进一段后向两边收窄，留出双标志的对称位置。
- 线条使用低饱和绿白，黑底不加其他彩色装饰。扫描纹、少量抖动与轻微色散统一覆盖网格和标志。
- 双标志停留后各自折成网片，再拉长成新的通道，最终淡黑。替换合作方时保持左右重量一致，折叠动作在留读后发生。

## 内容替换

- 替换两端标志，保留通道—双标志—折回通道的循环关系。
