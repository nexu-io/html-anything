# A paper geometry system for knowledge work

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-4cab572a-4d2a-4058-8a06-84cf3fda0df0`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/45576b4354fd8dba80ddb104981486033fc63cc07fa7785400517e85394d6483) · [Published package](https://r.open-design.ai/files/7ee3a8dd021349fa0610293f59f243257e79646a7921db68b8c8c1546abb286f). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
