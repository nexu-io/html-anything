# Figma — Roundtrip between code and canvas

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-b35abe81-509c-424a-9acf-347a8831b857`, stage the change and run `npm run templates:check`.
