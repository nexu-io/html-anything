# One task across phone and desktop

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-3845bb3e-dafb-4af2-9507-d32400b5aa54`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/fcbfe5db37b7370bf11a88c4f81c386c29056ed01ebfa2dee1a796b1f95a4e4d) · [Published package](https://r.open-design.ai/files/aeda480b1b5e233f4bf8df2a48844e98a66041786a690c65c14e29c94896fcd2). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
