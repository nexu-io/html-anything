- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-6b037a5c-ee23-47ce-b312-ba285d5e7ef4`, stage the change and run `npm run templates:check`.
