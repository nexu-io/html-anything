# Continuous symbol morphing

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-68d80741-c336-41ca-848e-7e6103e021e6`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/c760b04fcf65655c3c81dd85470708619e1873dfbc2353db84495b77a8a019e4) · [Published package](https://r.open-design.ai/files/8d0137cb85720cceba7b4ff0070f7e7480b011ba1868f87510975abc7a196ad5). Videos and duplicate archives remain in the CMS.
