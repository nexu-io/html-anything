# Repository lifecycle

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-927b643f-10c5-4c96-b2fe-f06bed85c9b8`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/8bbbd14761c01ac89784e5a15fa2692190918d9107b18c1a0f69e8e1a23c3e1a) · [Published package](https://r.open-design.ai/files/a285f853e1e3cc5cc22b0519d7c88dac96e8a02ae2b5302fc2df8a11bd86f886). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
