# Living waveform poster

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-cbe77bbc-94d8-4035-9507-103deaa025bc`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/385a9b521847c08833f75e737224e8d7f081e4e52e94f8b3ad8a7ebad541d100) · [Published package](https://r.open-design.ai/files/1c3a616eea5d75ffb46244ed3c27e123f4940ceafb88cd3837252210f6540f7e). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
