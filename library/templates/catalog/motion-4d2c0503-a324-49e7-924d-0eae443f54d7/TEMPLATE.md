# Figma — Figma in Weave

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-4d2c0503-a324-49e7-924d-0eae443f54d7`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/35c377d3f194ab8238623e8f3359262611a5e38692d9467d754d93fd2a5509c3) · [Published package](https://r.open-design.ai/files/e291004ee0d441884b14dc95c3f3d3228c78c419db56c454e025d312847536e4). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
