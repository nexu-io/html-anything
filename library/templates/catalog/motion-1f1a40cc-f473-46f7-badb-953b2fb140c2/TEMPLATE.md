# Movement reveals patterned glass

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-1f1a40cc-f473-46f7-badb-953b2fb140c2`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/21922e55482cb6ab64e56b6c7a34414cb2fbe5077bab8730e12cc7f85200c970) · [Published package](https://r.open-design.ai/files/2e50168f1f7c9acfef713015c4b9b8072348c937e5c4b8b634886fbb5f3d10c0). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
