# Figma — Draw inspiration

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-dfb1a35a-a70e-489f-8e02-b74068fc0b8c`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/9146aa9ea36464348758d7cb627a9b0f7fa977aab2ab3461632298093c3ef568) · [Published package](https://r.open-design.ai/files/b97d571410fa84a6841700a13bd9eb1fe04e23a2a7d702230f4d0a62d371ab80). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
