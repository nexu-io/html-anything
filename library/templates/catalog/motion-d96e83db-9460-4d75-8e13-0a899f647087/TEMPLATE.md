# Collaborative chat building

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-d96e83db-9460-4d75-8e13-0a899f647087`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/68b4991f7099e630453768d91647ae1d331c415143146e9d6521dc67053d3dd5) · [Published package](https://r.open-design.ai/files/88b8b7f3bc98c855ada2d0112b3413e1bd5278b1e2859601c1835ff5f88acb01). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
