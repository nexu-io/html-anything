# Personal assistant tasks

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-b6889c36-8aff-446f-8f2d-f958a8951a4c`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/4c2031270be18d1baa64b7000697420619db4eced65d8aa57c708e8f013ccefe) · [Published package](https://r.open-design.ai/files/87bf9f050a435bec90978d99fb1a3647e67432a80dfad0ee107446d34d54c86a). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
