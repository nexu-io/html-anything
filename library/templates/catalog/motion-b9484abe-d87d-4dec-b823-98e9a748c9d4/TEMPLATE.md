# Wide parallel research

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). Large reference images load from existing CMS URLs; an internet connection is required to view them. Original images remain in the published package.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-b9484abe-d87d-4dec-b823-98e9a748c9d4`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/3022277f486c8827c2ea561975cca629ecc3a4dbf109750d9f8e302011546da1) · [Published package](https://r.open-design.ai/files/0587932bd46af5eb5dd1e8e3c766dd41fde582f2267c438aecec90e286514d8c). Videos and duplicate archives remain in the CMS.
- Metadata, translations, remote asset identities and imported package identity: [template.json](template.json).
