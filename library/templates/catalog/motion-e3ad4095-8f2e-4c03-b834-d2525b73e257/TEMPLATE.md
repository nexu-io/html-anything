# From constrained to open creation

Reference guidance and authored HTML motion examples, not a verified complete Studio project.

- Read [motion.md](source/motion.md) and open [preview.html](source/preview.html). All guide images and demo files are local.
- Edit source in this folder; refresh its manifest with `npm run templates:manifest -- motion-e3ad4095-8f2e-4c03-b834-d2525b73e257`, stage the change and run `npm run templates:check`.
- [Reference video](https://r.open-design.ai/files/1f97e91a24a49207206e78867bd53e6c2fb8b455589dc8b690ac3d677e53f156) · [Published package](https://r.open-design.ai/files/189ccd2c2b2fa6f7caa96c20b7e97450084fc70ae12efbdd9ac8545b1a17bb7e). Videos and duplicate archives remain in the CMS.
- Metadata, translations and imported package identity: [template.json](template.json).
