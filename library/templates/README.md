# Editable templates

Start from the existing bundled projects. Their source stays in `template-library/` so Studio and this index use one maintained copy.

| Project | Duration | Try changing |
| --- | --- | --- |
| [Product Promo](../../template-library/product-promo/) | 20 seconds | Headline, product screenshots, reveal timing and closing copy. |
| [NYT Graph](../../template-library/nyt-graph/) | 15 seconds | Values, labels, chart explanation and annotations. |
| [Decision Tree](../../template-library/decision-tree/) | 10 seconds | Question, branch labels and reveal order. |

These are editable examples with source and posters. Open **Studio → Templates → Ready to edit** to create an independent project. Use [motion-template-to-video](../../skills/motion-template-to-video/SKILL.md) for adaptation. Preserve the [upstream license and notices](../../template-library/NOTICE.md); validate your own changed copy and export.

To contribute another template, use the [entry checklist](../ENTRY_TEMPLATE.md), supply the editable source, preview and `TEMPLATE.md` instructions, and record the version and changes you actually tested. Follow the existing [template-production workflow](../../skills/motion-video-to-template/SKILL.md) when producing a reusable template from a video. Adding a folder here alone does not register a Studio template.

## Agent-ready template direction

A community template should let a person judge its result and an agent understand how to adapt it. Include editable source, a preview, replaceable content, asset paths, source/license notes and the relevant Motion MD or Brandkit references. Use the [entry checklist](../ENTRY_TEMPLATE.md).

Today, select a bundled template and pass a brief to `motion-template-to-video`; for an external reference, use `motion-recreate`. The gallery action prepares the agent handoff. Automatic discovery, installation, personalization and feedback-informed optimization are planned in the [Studio blueprint](../../docs/product/studio-vision.md). Existing reference entries do not become executable templates simply by appearing in the catalog.

## Presenter-led video starting points

For **real people + motion**, browse the [nine creator-video references and MotionGit demo](../../README.md#creator-video-gallery), then select one of the [three presenter-story recipes](../skills/presenter-story/SKILL.md). Bring your own camera take, screen recording and measured captions. The recipe guides the edit; an external video reference needs reconstruction and review before becoming an editable template.

| Story | Reusable design recipe | Materials to bring |
| --- | --- | --- |
| Teach a set of ideas | [Presenter listicle](../skills/presenter-story/references/presenter-listicle/MOTION_DESIGN.md) | Presenter recording, point list, supporting screenshots |
| Demonstrate a workflow | [Workflow demo](../skills/presenter-story/references/workflow-demo/MOTION_DESIGN.md) | Camera take, screen recording, actual speech timing |
| Explain a product | [Product walkthrough](../skills/presenter-story/references/product-walkthrough/MOTION_DESIGN.md) | Presenter, real product capture, result and approved facts |

[MotionGit Kinetic Tech](https://github.com/motiontemplates/385712) is an external template reference with its own package and runtime. Its demo combines a presenter window and motion; OpenMotion import compatibility is not verified. The three built-in projects above remain the only bundled Studio templates.
