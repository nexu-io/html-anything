# Model and provider marks

The model wall follows the built-in entries in [the gateway catalog](../../../gateway/catalog.ts). Badges label the model; where a model mark is unavailable, the icon identifies its developer (ByteDance for Seedance, Alibaba for Wan, Google for Veo) or its serving provider (fal.ai for Kokoro). The separate requests row is not part of the built-in catalog.

Artwork: [Lobe Icons](https://github.com/lobehub/lobe-icons), static SVG package 1.102.0, [MIT license](LICENSE.txt). Brand marks belong to their respective owners.

Agent badges in the [adjacent folder](../agents): The [Codex](https://developers.openai.com/codex/) icon also appears in the walkthrough. The other icons come from the [Claude Code docs](https://code.claude.com/docs/mintlify-assets/_mintlify/favicons/claude-code/pLsy-mRpNksna2sx/_generated/favicon/android-chrome-192x192.png), [DeepSeek Harness repository](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/web/public/icon-192.png) and [WorkBuddy website](https://download.codebuddy.cn/web/workbuddy/eb02746771ab068964c9ce8804176ef2692ddd80/assets/logo.svg). Each mark identifies its respective client.

The [21-agent gallery](../agents/opendesign-gallery.png) reproduces the logo wall from the [OpenDesign compatibility guide](https://github.com/nexu-io/open-design/blob/07a86b1041531bfa0bec1006d9c0993985fee560/README.md#platform-compatibility). The [mobile layout](../agents/opendesign-gallery.mobile.png) uses the same tiles in three columns. This gallery represents the OpenDesign ecosystem. The four OpenMotion installation targets are documented in the [adapter guide](../../agent-adapters.md).
