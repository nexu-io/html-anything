## 2026-11-07：Prism 模板目录与本地检索

- **问题与对象：** 本机 Agent 和 Studio 用户需要使用同一批可编辑模板，模板更新无需重新打包插件。
- **实现：** 复用已发布的 Prism JSON、ETag 缓存和现有界面分页；公开目录获取、按 ID 读详情两个工具，一期共 11 个。list 只返回本地 JSONL 路径，检索交给宿主工具。下载文件沿用现有项目创建、版本和回滚流程。
- **范围：** 本地 DEV/prod 内容读取、缓存、界面目录更新与远程模板创建。新落地页、CMS 内容编辑/生产发布及云端文件访问不包含在本次。现有账户、价格、用户画像与商业化不变。
- **版本：** 0.6.3 本地候选，防止复用旧版共享服务；不代表已发布。
- **环境：** 本地开发默认 DEV，正式打包默认线上；DEV 包显式指定并随包保存环境。默认工作区、后台与目录缓存隔离，不跨环境回退。
- **验证：** 静态检查、Studio 类型检查/构建与目录界面回归通过；目录测试覆盖 304、跨重启缓存、更新失败保留旧版、文件完整性、失败工程清理和环境隔离。DEV ZIP 解压后以真实 stdio 调用 list/get，未设置环境覆盖也读到 DEV 的 20 个发布模板和 3 个内置示例；实际模板文件可创建工程并在 Studio 打开时间轴，目录预览 MP4 可播放。正式/DEV ZIP 与 npm 产物的环境配置分别检查。
- **待验收：** 本次线上目录返回 404，线上内容尚未验证；抽查模板在 Studio 出现嵌套结构检查项，模板内容质量仍需单独验收。本次未重复完整 MP4 导出及其他平台安装验收，也未发布。
- **补充集成检查：** 本机真实多个 stdio MCP 客户端共用服务、独立工程、并发冲突和重新连接回归通过。完整 ZIP 出片结果以本 PR 的独立 CI 执行为准，不把已有浏览器预览当作导出验收。

## 2026-11-06：五个 Skill、界面与双语介绍同步

- **问题与对象：** 现有 Agent 用户、模板作者和仓库贡献者需要一致的 Skill 名称、安装包和使用说明，避免改名后引导失效或打包漏项。
- **选择与影响：** 一期同装 motion-production、motion-director、motion-template-to-video、motion-recreate、motion-video-to-template。MCP 短 workflow ID 保持兼容，专业任务可直接进入；production 承接既定创作决定下的工程操作。公开 Tools 仍为九个。
- **界面：** 同步 OpenDesign 双主题、字体、按钮、表单与浮层材质，不改变作品 iframe 的样式、工程格式与原有布局职责。
- **文档：** 新增中英文介绍、Motion MD v0.1 提案、示例与资源索引。Motion MD 由用户显式提供给 Agent，尚无自动导入器；主题集合站与 Arena 仍为规划。旧中文首页保留跳转，仓库仍以 feature/motion 开发，main 与 legacy 留档流程见迁移说明。
- **公开与分发：** 保留独立 npm、两套依赖锁、正向打包清单、Apache-2.0 和上游/字体许可，以及浏览器统计发送逻辑移除。五入口与所引用的公开文档、工作流发现模块一起进入 npm/ZIP；不导入私有历史、过程档案或发布配置。
- **验证：** 按本次 PR 的确切提交运行静态检查、Studio 类型/构建/回归、安装及适配器测试、五入口 npm/ZIP 清单与九 Tool E2E；实际结果写在 PR。目标机/宿主加载、模型创作、正常速度审听与视觉验收另列，不从旧结果推定。
- **画像与商业影响：** 改善现有本地创作及模板复用入口，不新增用户研究结论、账号、价格、付费能力或发布。
