# Motion Design Skill 包：真人故事与六组源码改编

本文区分三份真人叙事设计配方（附上游原片 / 改编演示）与六组可执行源码改编；真人配方仍需结合你的素材实际制作。

六组源码改编均使用固定上游源码，在保留动效实现的前提下替换内容。左侧为原始内容，右侧为实际改编。这里展示的是可编辑源码复用，不将别人的原片写成 OpenMotion 的生成结果。所有片段无声，时间与来源见 [evidence.json](../library/skills/openmotion-design-remix/evidence.json)。

### 🎙️ 真人表达 × Motion：让你的故事成为主角

口播、工具教程、产品演示，同样可以沉淀为 Motion Design。**保留人物表达与叙事节奏，把字幕、截图、画中画和动效编排一起复用；换成你的录制、主题和品牌。**

下面三组为现有目录收录的 **Hyperframes 原片 / 上游改编演示**，两侧是各自的无声节选，并非同步还原评测或 OpenMotion 新生成的结果。每组附有可交给 Agent 的设计配方；你的成片需要结合自己的素材制作并验收。

## 怎么复用

[读取 Skill](../library/skills/openmotion-design-remix/SKILL.md)，选择 profile，把 preset 复制到包外改成自己的内容，然后生成新工程。每个 profile 的 Motion MD 说明保持项、素材要求和检查重点。

```sh
cd library/skills/openmotion-design-remix
node scripts/materialize.mjs wireframe-portal-title remix /tmp/my-portal
```

UI 案例保留部分原品牌示意画面，不是当前 OpenMotion 界面截图；代码与数值是演示文案，不代表产品 API 或经营数据。完整运行依赖与许可见 [NOTICE](../library/skills/openmotion-design-remix/NOTICE.md)。
