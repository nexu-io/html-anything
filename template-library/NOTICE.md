# Hyperframes official examples

Source: https://github.com/heygen-com/hyperframes/tree/3baf81f9a92615507f76fe8de33e489034ee77ec/registry/examples

Upstream project: HeyGen Hyperframes. Distributed under the upstream Apache-2.0 license in `LICENSE`.

Included examples: Product Promo, NYT Graph, Decision Tree. Source files and registry metadata originate at the above commit. OpenMotion adds local browser scripts/fonts and updates resource paths and registry asset entries. Each template now contains the exact GSAP 3.14.2 browser script and its fonts in vendor/, including dependency licenses and hashes. Creation retains the native Hyperframes project configuration. No remote font or CDN request is required by these templates; execution tools still need installation. Original example artwork remains credited upstream.

The gallery posters are captured from these examples using Hyperframes snapshot.
