A FEW THINGS TO KNOW
你可能想知道
从连接到创作，都很简单。

      
需要先准备素材或填写提示词吗？ 
不需要。选一个模板，复制复刻指令发给 Agent，即可沿用模板的主题与内容开始。想换成自己的产品、照片或文案时，再补充即可。

      
生成的视频还能继续编辑吗？ 
可以。模板会成为可编辑项目，你可以调整镜头、文字、颜色与节奏，也可以继续让 Agent 修改。保存项目文件后，可带着素材继续创作。

      
已经连接过，还要重新接入吗？ 
不需要。Agent 会优先复用指向当前工作区的连接。若找不到工具，可按宿主提示重新打开会话，或检查配置中的数据目录。

      
需要一直打开这个弹框吗？ 
不需要。连接后关闭弹框，继续在当前项目里编辑。导出时请保持编辑器在前台；本地服务需要继续运行。

      
哪些 Agent 可以使用？ 
支持 Codex、Claude Code、DeepSeek Harness 和兼容 stdio MCP 的本机工具。ChatGPT 云端需要公开 HTTPS MCP 服务，当前版本尚未提供。选择客户端后，配置、下载文件和使用指引会同步切换。
