FAQ

关于 Dark Mode 的常见问题

"真正的 OLED 黑"和普通深色模式有什么区别？ +
普通深色模式背景多为 #1f1f22 一类的深灰，OLED 像素仍在发光；Taskflow 2.0 把画布压到 #08090a，让纯黑区域像素近乎关闭，因此能省电约 40%。
日升日落自动切换会突然闪屏吗？ +
不会。切换读取系统的"自动外观"与日出日落时间，走原生平滑过渡动画，没有闪屏，也不会打断你正在编辑的任务。
快捷键除了 J / K / Space 还有哪些？ +
J / K 用于上下翻动任务，空格用于完成当前任务。除此之外，导航、优先级、筛选与命令面板均做到全键位覆盖，手不离键盘即可完成日常操作。
我的设备不是 OLED，还能用吗？ +
可以。深色体验、自动切换、快捷键与 120fps 滚动在所有屏幕上均可用；省电 40% 的收益主要体现在 OLED 屏幕上。
升级 Dark Mode 需要额外付费吗？ +
不需要。现在即可免费升级，所有付费计划（含 Free）均可使用 Dark Mode，不设额外付费墙。
120fps 滚动需要什么硬件？ +
在支持高刷新率（90Hz / 120Hz）的屏幕上，任务列表滚动可稳定输出 120fps；普通 60Hz 屏幕则按其上限流畅呈现。
